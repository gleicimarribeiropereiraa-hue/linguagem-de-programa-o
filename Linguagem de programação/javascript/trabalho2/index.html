Atividades de HTML e JavaScript

Três exercícios com entrada de dados, processamento e resultados.

Questão 1 — Saudação por turno

Digite M para Matutino, V para Vespertino ou N para Noturno.


Questão 2 — Média e conceito do aluno

Informe as duas notas parciais. O sistema calculará a média, o conceito e a situação.


A média e o conceito serão exibidos em uma janela de alerta, conforme solicitado no enunciado.

Questão 3 — Reajuste salarial

Informe o salário atual do colaborador para calcular o percentual de reajuste e o novo salário.


Faixas adotadas: até R$ 2.800,00 = 20%; acima de R$ 2.800,00 até R$ 7.000,00 = 15%; acima de R$ 7.000,00 até R$ 15.000,00 = 10%; acima de R$ 15.000,00 = 5%.
