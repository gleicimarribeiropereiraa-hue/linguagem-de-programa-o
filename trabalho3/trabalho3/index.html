O que é uma estrutura condicional SE de o exemplo

è uma estrutura de decisão onde você define a execução de um trecho do código caso a condição seja atendida por exemplo If(numero > 4){ numero++; } else{ "Numero é igual a 4"; }

Para que serve o Else

O else cria um caminho alternativo,onde caso a condição do if for falsa automáticamente executa o código do Else; exemplo If(numero == 4){ numero++; } else{ alert("Numero não é igual a 4"); }

Qual é a funcionalidade do FOR(Para) em programação?

É um laço de repetição usado para repetir um determinado número de vezes ou para poder percorrer todos os itens de uma coleção de dados for(let i,i < 5,i++){ alert("Acrescimo de I"+ i) }

Quais são as estruturas condicionais e as estruturas de repetição

• Condicional Simples (if / se): Executa um bloco de código apenas se a condição for verdadeira. • Condicional Composta (if - else / se - senão): Executa um bloco de código se a condição for verdadeira e outro bloco alternativo se ela for falsa. • Condicional Aninhada / Múltipla (if - else if - else / escolha - caso ou switch - case): Permite testar múltiplas condições em sequência ou selecionar entre várias opções fixas de valor. • Operador Ternário: Uma forma compacta de escrever um if-else simples em uma única linha (ex: condicao ? valorSeVerdadeiro : valorSeFalso).

Quais são os tipos de input para texto, numeros e datas?

• : Campo de linha única para texto livre (como nome, endereço ou título). É o padrão do elemento se nenhum tipo for declarado. • : Campo de texto onde os caracteres são mascarados (para senhas). • : Campo otimizado para endereços de e-mail (com validação básica no navegador). • : Campo estilizado para termos de pesquisa (costuma incluir um botão para limpar o texto rapidamente). • : Campo destinado a números de telefone (em celulares, abre o teclado numérico). • : Campo para endereços de sites/URLs. • textarea (elemento relacionado): Usado para textos longos de múltiplas linhas. Datas e Horas • : Seleção de uma data (formato padrão de envio: YYYY-MM-DD). • : Seleção de horário (formato HH:MM). • : Seleção combinada de data e hora locais (sem fuso horário, formato YYYY-MM-DDTHH:MM). • : Seleção de ano e mês. • : Seleção de ano e número da semana. Números • : Campo para valores numéricos, permitindo definir limites mínimos (min), máximos (max) e incrementos (step), além de exibir setas de ajuste. • : Controle deslizante (slider) para escolher um valor numérico dentro de um intervalo.
