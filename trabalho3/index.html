Função em JS

Função é um bloco de código criado para executar uma determinda tarefa,você pode criar uma função e executar ela N vezes,ao chamar a mesma em qualquer parte do seu código.

O que é uma estrutura condicional SE de o exemplo

è uma estrutura de decisão onde você define a execução de um trecho do código caso a condição seja atendida por exemplo If(numero > 4){ numero++; } else{ "Numero é igual a 4"; }

Para que serve o Else

O else cria um caminho alternativo,onde caso a condição do if for falsa automáticamente executa o código do Else; exemplo If(numero == 4){ numero++; } else{ "Numero é igual a 4"; }
